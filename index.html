04AI practice

AI is not aside quest.

It is where the documentation has to land now: knowledge an agent can retrieve, prompts that keep a conversation on brand, and the judgement to know what should stay human.

02 Structure Query-first IA, retrieval-ready chunks

04 Agent An existing support agent, answering live

In productionSupport that runs on documents

  • ElevenLabs voice agent — built and maintained the knowledge base a live support agent answers from, then prompted that agent to use it clearly and consistently.
  • 250+ article knowledge base — written, tagged and structured so an agent can find the right answer without a human.
  • Salesforce documentation suite — six content domains organised for retrieval, not just for reading.
  • Bitrix24 + ChatGPT lead flow — documented the architecture, authentication and routing rules behind an automated enquiry filter.

PracticeHow I work with a model

  • Write for retrieval first. The best answer is written in the shape of the question someone will actually ask.
  • Prompt like a spec. Persona, tone limits, fallback paths and escalation — not a paragraph of vibes.
  • Test on real conversations. A prompt earns its place against customer transcripts, not a demo.
  • Keep the human seam visible. Every flow I write knows when to hand the conversation over.
